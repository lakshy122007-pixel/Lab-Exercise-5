### Scenario 1: Health App

**Problem Statement:**
*Patients need a way to easily track their medicines and appointments because they may forget schedules, which results in missed medications and appointments.*

**Research Methods:**

* **Interviews:** To understand patients' difficulties and requirements.
* **Surveys:** To collect information from a larger group of users.
* **Usability Testing:** To check whether users can easily navigate the app.

**Persona 1 – Patient**

| Category     | Details                              |
| ------------ | ------------------------------------ |
| Demographics | 45 years old, working professional   |
| Goals        | Track medicines and appointments     |
| Behaviors    | Uses mobile apps regularly           |
| Pain Points  | Forgets medicine timings             |
| Motivation   | Wants to manage health independently |

**Persona 2 – Elderly User**

| Category     | Details                               |
| ------------ | ------------------------------------- |
| Demographics | 65 years old, retired                 |
| Goals        | Receive simple health reminders       |
| Behaviors    | Uses smartphone occasionally          |
| Pain Points  | Small text and complicated interfaces |
| Motivation   | Wants an easy and reliable health app |

### Scenario 2: E-Commerce Website

**Problem Statement:**
*Online shoppers need a way to quickly find and compare products because large numbers of choices make shopping difficult, which results in confusion and abandoned purchases.*

**Research Methods:**

* **Surveys:** To understand shopping preferences.
* **Interviews:** To identify common shopping difficulties.
* **Usability Testing:** To observe how users search, compare, and purchase products.

**Persona 1 – College Student**

| Category     | Details                                       |
| ------------ | --------------------------------------------- |

| Goals        | Find affordable products quickly              |
| Behaviors    | Shops mainly through mobile                   |
| Pain Points  | Too many choices and unclear prices           |
| Motivation   | Wants convenient and budget-friendly shopping |

**Persona 2 – Working Professional**

| Category     | Details                            |
| ------------ | ---------------------------------- |
| Demographics | 30 years old, working professional |
| Goals        | Purchase quality products quickly  |
| Behaviors    | Compares products and reviews      |
